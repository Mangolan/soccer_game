# 적응형 AI 기술 문서

## 1. 목적과 범위

오른쪽 AI는 난이도별 규칙 AI를 기본 동작으로 유지하면서, 최근 20초간 관측한 왼쪽 플레이어의 행동에 따라 수비·점프·역습·슈팅 정책을 실시간으로 바꾼다. 이는 학습 모델이 아니라 설명 가능한 휴리스틱 기반 적응 계층이다. 분석 결과는 경기 화면 오른쪽 위에 유형, 신뢰도, 공격 방향, 판단 근거로 표시된다.

구현 위치는 다음과 같다.

- `lib/game/adaptive_ai.dart`: 20초 행동 창, 유형 판정, 전략 매핑
- `lib/game/game_logic.dart`: 상태 수집과 AI 이동·점프·역습·슈팅 반영
- `lib/game/game_widget.dart`: 화면의 분석 근거 패널

## 2. 상태 입력

`PlayerBehaviorAnalyzer.record()`가 실행 중인 매 프레임 다음 값을 받는다.

| 입력 | 단위/범위 | 수집 방법 | 사용 목적 |
|---|---:|---|---|
| 경과 시간 `dt` | 초 | 게임 틱 | 프레임레이트와 무관한 시간 가중 집계 |
| 플레이어 위치 | 0.0~1.0 | `leftPlayer.x / worldWidth` | 평균 위치와 수비 성향 계산 |
| 수평 속도 | px/s | `leftPlayer.vel.dx` | 최근 공격 방향 계산 |
| 전진 입력 | boolean | 오른쪽 입력, 왼쪽 공격 기준 | 전진 성향 계산 |
| 점프 시작 | boolean | 눌림 에지 검출 | 분당 점프 빈도 계산 |
| 공 근접 여부 | boolean | 선수·공 반지름과 32px 여유 거리 | 점프 공격/일반 점프 구분 |

샘플은 최근 20초만 유지한다. 위치와 전진 성향은 샘플 수가 아니라 `dt`로 가중하므로 60Hz와 120Hz에서 같은 행동이 같은 값으로 계산된다. 킥오프나 경기 재시작 시 이전 경기의 분석 이력은 초기화된다.

## 3. 판단 과정

판단 흐름은 다음과 같다.

```text
프레임 상태 수집
  → 20초보다 오래된 샘플 제거
  → 점프/분, 점프 공격 비율, 전진 시간 비율, 평균 위치, 공격 방향 계산
  → 최소 3초 관찰 여부 확인
  → 점프형 → 돌진형 → 수비형 → 혼합형 순서로 판정
  → 유형별 AdaptiveAiStrategy 생성
  → 같은 게임 틱부터 AI 행동과 화면 근거에 반영
```

분류 우선순위와 기준은 다음과 같다.

| 유형 | 판정 기준 |
|---|---|
| 점프형 | 관찰 3초 이상, 분당 점프 10회 이상, 공 근처 점프 50% 이상 |
| 돌진형 | 관찰 3초 이상, 전진 입력 58% 이상, 평균 위치 43% 이상 |
| 수비형 | 관찰 3초 이상, 전진 입력 28% 이하, 평균 위치 43% 이하 |
| 혼합형 | 관찰 3초 미만이거나 위 조건에 해당하지 않음 |

신뢰도는 `min(관찰 시간 / 20초, 1)`이다. 공격 방향은 수평 이동 누적값이 시간당 임계값을 넘으면 왼쪽/오른쪽, 그렇지 않으면 중립으로 표시한다.

## 4. 전략 변경

| 상대 유형 | 수비 거리 배율 | 점프 예측 보정 | 점프 확률/쿨다운 | 역습 확률 | 슈팅 정책 |
|---|---:|---:|---:|---:|---|
| 점프형 | 1.42 | +0.16초 | 1.28배 / 0.82배 | 74% | 낮고 빠른 역습 |
| 돌진형 | 1.28 | +0.08초 | 1.08배 / 0.92배 | 68% | 빠른 직선 슈팅 |
| 수비형 | 0.72 | -0.02초 | 0.82배 / 1.12배 | 38% | 높은 롭슈팅 |
| 혼합형 | 1.00 | 보정 없음 | 1.00배 / 1.00배 | 50% | 균형 슈팅 |

전략 값은 다음 실제 로직에 사용된다.

- 수비 거리: 공 뒤에서 잡는 AI 목표 X 오프셋에 배율 적용
- 점프: 공의 예상 Y 계산 시 선행 시간을 더하고, 점프 가능 거리·확률·쿨다운 변경
- 역습: 공이 AI 진영으로 빠르게 들어올 때 확률 추첨 후 1.35초간 전진 커밋
- 슈팅: 마무리 슈팅과 일반 공 접촉 모두에서 수평 속도와 높이를 정책별로 변경

화면에는 예를 들어 `상대 분석: 점프 공격 74% → 낮은 역습 전략 적용`처럼 가장 강한 판단 근거 하나를 표시한다. 최근 행동이 달라지면 오래된 샘플이 빠지면서 유형과 전략도 다시 바뀐다.

## 5. 기존 규칙 AI와 평가 지표 비교

| 평가 지표 | 정의 | 기존 규칙 AI | 적응형 AI | 현재 결과/상태 |
|---|---|---|---|---|
| AI 승률 | AI 승리 경기 / 완료 경기 | 난이도별 고정 정책 | 상대 유형별 정책 | 실제 A/B 경기 표본이 없어 N/A |
| 평균 반응 시간 | 행동 변화 시작부터 전략 변경까지 | 공 판단 0.07~0.32초 | 최소 분류 3초, 이후 프레임마다 최근 창 재평가 | 시뮬레이션에서 5초 반복 입력 후 유형 변경 검증 |
| 플레이 다양성 | 서로 다른 수비·점프·역습·슈팅 정책 수 | 난이도당 고정 정책 1세트 | 유형별 정책 4세트 | 테스트에서 3개 반복 행동이 서로 다른 3개 정책을 선택함 |
| 설명 가능성 | 플레이어가 판단 근거를 확인 가능한지 | 없음 | 유형·신뢰도·방향·근거 표시 | 위젯 구현 및 화면 시연 |

승률은 실제 표본 없이 임의 수치를 작성하지 않는다. 정식 A/B 평가는 동일 난이도에서 이용자를 규칙 AI(A)와 적응형 AI(B)에 50:50 무작위 배정하고, 난이도별 최소 200경기를 수집한다. AI 승률, 평균 득실점 차, 행동 변화→전략 변경 시간, 경기당 서로 다른 슈팅 정책 수를 95% 신뢰구간 및 표본 수와 함께 기록한다.

## 6. 테스트와 재현 방법

| 테스트 | 검증 내용 |
|---|---|
| `test/adaptive_ai_test.dart` | 분류 임계값, 전략 매핑, 20초 슬라이딩 창 |
| `test/game_logic_test.dart` | 킥오프/초기화, 이동과 점프 입력, 득점, AI 진단 상태 |
| `test/ai_behavior_simulation_test.dart` | 반복 돌진·공격 점프·수비 행동을 실제 `GameState.update()`에 공급하고 서로 다른 전략 선택 검증 |

전체 검증 명령은 `flutter test --no-pub`이다. 시뮬레이션에는 난수 시드를 주입해 결과를 재현 가능하게 만들었다.

60~90초 시연 영상은 저장소에 포함하지 않고 제출 안내에 따라 MP4 파일로 별도 첨부한다. 영상은 경기 시작 후 같은 오른쪽 이동 행동을 반복하고, 화면 분석이 초기 혼합형에서 돌진형으로 바뀌며 수비 거리·역습·직선 슈팅 정책이 선택되는 장면을 보여준다.

## 7. 한계

- 머신러닝 모델이 아니라 고정 임계값 기반이므로 경계값 부근에서 유형이 오갈 수 있다.
- 최근 20초만 사용하므로 장기적인 사용자 성향을 경기 간에 기억하지 않는다.
- 점프 공격은 공과의 거리로만 판단하며 실제 슈팅 성공 여부나 접촉 각도까지 학습하지 않는다.
- 역습은 확률적이어서 같은 유형에서도 매번 같은 행동을 보장하지 않는다. 테스트에서는 난수 시드로 재현한다.
- 화면은 공간 제약 때문에 모든 입력값이 아니라 가장 강한 근거 하나만 보여준다.
- 실제 이용자 A/B 표본이 없으므로 승률 향상은 아직 입증되지 않았다.
- 현재 분류 임계값은 게임 물리와 맵 크기에 맞춘 초기값이며 사용자 데이터 수집 후 재보정이 필요하다.
